这篇主要讲具体怎么操作，以及下单时有哪些地方值得注意。

## 先进入 codexpro.vip 选择套餐

打开 `https://codexpro.vip` 后，进入 ChatGPT 会员或套餐购买页面，根据自己的使用需求选择对应套餐。

如果平时主要是聊天、写文章、查资料、处理文件、生成图片，或者偶尔辅助写代码，通常可以先看 ChatGPT Plus。

如果平时 Codex 用得比较多，经常处理大型代码项目，或者本身对使用额度要求比较高，可以再根据页面实际提供的套餐考虑 Pro。

具体套餐名称、价格、可购买状态以及包含的额度，建议都以网站下单页面当时显示的信息为准。

提交订单之前，最好再核对一遍套餐，避免买错。

## 填写下单通知邮箱

选择套餐以后，会进入订单填写页面。

这里通常需要填写一个邮箱，用来接收订单信息、查询记录或者后续售后通知。

很多第一次充值的人会把这里和 ChatGPT 登录邮箱混在一起。

实际上，下单通知邮箱主要用于接收订单信息，最终需要充值到哪个 ChatGPT 账号，一般会在后面的自助充值环节再次确认。

所以这里建议填写一个自己长期能正常接收邮件的邮箱，方便后面查订单。

## 选择微信或支付宝付款

订单信息确认以后，就可以进入付款页面。

如果页面提供微信和支付宝，可以直接选择自己方便的付款方式完成支付。

对于没有海外信用卡的用户来说，这种方式会省掉不少步骤，不需要专门准备国外银行卡，也不用反复研究虚拟卡、账单地址或者其他海外支付方式。

付款成功以后，不建议马上关闭网页。

先确认订单状态，并把订单号、订单页面或者支付记录保存下来。

后面如果需要查询进度或者联系售后，这些信息都会比较有用。

## 付款后查看订单和充值凭证

支付完成以后，一般会进入订单详情页面。

如果订单页面提供订单号、兑换码、充值凭证或者其他用于自助充值的信息，建议先保存下来。

这些信息后面可能会用在：

查询订单状态、进入自助充值、核对充值结果，或者出现异常以后联系客服处理。

尤其是第一次操作，可以顺手截个图，避免刷新或者关闭页面之后找不到。

## 进入自助充值页面

拿到订单对应的充值信息以后，就可以按照页面提示进入自助充值环节。

这一步建议始终使用自己的 ChatGPT 账号操作。

如果页面采用的是自助授权、账号识别或者其他无需直接提交密码的方式，就按照页面提示完成即可。

不要把自己的 ChatGPT 密码、Google 密码、Apple ID 密码或者邮箱密码直接发送给陌生人。

能够自己登录账号、自己确认充值对象，会更加稳妥。

## 提交之前一定核对 ChatGPT 账号

这是整个流程里比较容易出错的一步。

如果你手里有多个 ChatGPT 账号，或者分别使用过邮箱登录、Google 登录、Apple 登录，很容易出现“自己以为是这个账号，实际登录的是另一个账号”的情况。

所以系统识别出账号以后，不要马上提交。

先检查页面显示的邮箱或者账号信息，确认它确实是你准备开通 Plus / Pro 的那个账号。

尤其是长期使用的主账号，更建议认真核对一次。

一旦把充值提交到错误账号，后续处理通常会麻烦很多。

## 如果充值失败怎么办

如果已经完成微信或支付宝付款，但后面的充值没有成功，不建议连续重复购买。

先保存当前订单号、支付记录和页面提示，再根据 `codexpro.vip` 当时页面显示的售后规则联系客服处理。

如果订单页面明确标注支持充值失败退款、未使用凭证退款或者其他售后方式，可以按照对应规则申请处理。

具体退款条件、到账时间和售后范围，还是以实际订单页面和平台当时公布的规则为准。

这样写也比较稳妥，因为不同套餐或者不同订单状态，处理方式可能不完全一样。
